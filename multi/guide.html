사장님 안내서

출퇴근 찍기, 휴무신청, 근무표를 한 앱에서 해요. 앱스토어 설치 없이 링크로 써요. 비용은 없어요.

지금 되는 것
  • 출근·퇴근 버튼 (매장 와이파이로 확인)
  • 알바 휴무신청 → 근무표 짜기·확정
  • 오늘 출근 현황, 지각, 기록 고치기
  • 월 근무 기록 (직원별 시간) → 엑셀로 내려받기
아직 없는 것
  • 급여 계산·정산표: 지금은 월 근무 기록 엑셀을 보고 하던 방식대로 계산해 주세요 (곧 추가)
  • 알림

1매장 만들기 (5분)

  1. 대표님이 보낸 매장 만들기 초대 링크를 폰에서 열어요
  2. [사장님 · 구글로 로그인] → 구글 계정 고르기
  3. [초대받은 매장 만들기] → 매장 이름, 정시 출근, 기본 시급, 급여일, 휴무신청 받는 시간, 요일별 필요한 알바 수 넣기
  4. [매장 만들기]. 규칙은 나중에 [규칙 바꾸기]에서 언제든 바꿀 수 있어요 (이번 달부터 / 다음 달부터)

초대 링크는 한 번만 쓸 수 있어요. 매장을 만든 구글 계정으로만 사장님 화면이 열려요.

2홈 화면에 추가

  • 아이폰: Safari로 열고 → 아래 공유 버튼 → 홈 화면에 추가
  • 안드로이드: 크롬으로 열고 → 오른쪽 위 ⋮ → 홈 화면에 추가

직원들에게도 똑같이 하라고 알려 주세요. 앱처럼 열려요.

3매장 안에서 한 번 (중요)

  1. 폰을 매장 와이파이에 연결 (모바일 데이터 말고)
  2. 매장 화면 맨 아래 [이 와이파이를 매장으로 등록]. 와이파이가 둘이면 각각 연결해서 한 번씩
  3. [지금 위치를 매장 위치로] (퇴근 확인용, 반경 기본 100m)
꼭 매장에서 해 주세요

집에서 등록하면 직원 출근에 전부 ⚠가 붙어요. 잘못 등록했으면 매장에서 [처음부터 다시]를 누르면 돼요. 출근에 ⚠가 갑자기 많아지면 인터넷 회선 주소가 바뀐 거라 매장에서 다시 등록해 주세요.

4직원 가입

  1. 직원에게 매장 이름을 알려 주세요. 직원은 앱 첫 화면 [직원 · 로그인 / 가입] → 매장 이름 검색 → 가입 신청
    (매장 화면의 직원 가입 링크·QR을 단톡방에 올리면 검색 없이 바로 돼요)
  2. 직원이 이름(실명) + 비밀번호(숫자 6자리, 본인이 정함)로 가입 신청
  3. 매장 화면 위에 뜨는 가입 신청에서 본인이 맞는지 보고 [승인]
  4. 직원 옆 [설정]: 정직원/알바, 매니저, 개인 정시 출근(다르면) · 비밀번호 임의 재설정 · 퇴사 처리

초대 링크가 밖으로 퍼졌으면 [새 링크로 바꾸기]. 옛 링크는 바로 막혀요. 주민번호는 앱에 넣지 않아요 (세무사에게 따로).

5매일: 출퇴근

  • 출근: 직원이 매장 와이파이에 연결하고 [출근]. 일찍 찍어도 계산은 정시부터, 늦으면 찍은 시각부터
  • 퇴근: 직원이 폰을 들고 사장님이나 매니저에게 와서 눌러 달라고 해요. 아무도 없으면 [혼자 퇴근] → ⚠
  • 매장 와이파이가 아니면 막지 않고 ⚠가 붙어요 → 매장 화면 [확인 필요]에서 [확인] 또는 [시각 고치기]
  • [오늘 출근 현황]: 누가 왔는지, 지각, 빠진 기록 넣기·고치기, 일찍 부르기(정시보다 일찍 나오라고 한 사람)
  • 출근을 안 찍은 날은 정시부터 계산해요. 퇴근을 안 찍은 날은 0시간이라 꼭 넣어 주세요

6매주: 휴무신청 → 근무표

  1. 알바가 정해진 시간(기본: 금 0시 ~ 토 22시)에 다음 주 못 나오는 날을 신청
  2. 사장님·매니저: [휴무신청 현황]에서 날짜별 가능 인원, 부족한 날 보기 (단톡 멘트 복사)
  3. [근무표 짜기]: 휴무신청 반영 → 빈칸 자동 채우기(초안) → 칸 눌러 고치기 → [확정]
  4. 확정해야 직원 폰에 보여요

7매달: 근무 기록 → 급여

  1. 매장 화면 [월 근무 기록 · 엑셀] → 달 고르기
  2. ⚠, 퇴근 없음이 남아 있으면 먼저 고치기
  3. [엑셀로 내려받기] → 직원별 일한 날·시간, 날짜별 출퇴근이 들어 있어요. 이걸로 급여 계산
  4. [이 달 합계 보내기]: 대표님께 전체 근무 시간·인원만 보내요

자주 묻는 것

아이폰인데 매장에서 찍어도 ⚠가 떠요

설정 → Wi-Fi → 매장 와이파이 옆 ⓘ → IP 주소 추적 제한 끄기. 그래도 뜨면 와이파이를 껐다 켜기.

직원이 번호 6자리를 잊었어요

직원 옆 [설정] → [비밀번호 임의 재설정] → 나온 임시 비밀번호 6자리를 [카톡 문구 복사]로 본인에게만 보내요. 직원이 이름 + 임시 비밀번호로 로그인하면 새 비밀번호를 직접 정해요.

직원이 그만뒀어요

직원 옆 [설정] → [퇴사 처리]. 로그인·출퇴근·근무표에서 빠지고, 지난 근무 기록은 그대로 남아요. 다시 일하면 직원 목록 아래 "퇴사한 직원"에서 [다시 일함].

폰을 바꿨어요 / 로그아웃됐어요

직원: 앱 첫 화면 [직원 · 로그인 / 가입] → (처음 쓰는 폰이면 매장 이름 검색) → [로그인] → 이름 + 비밀번호. 사장님: 같은 구글 계정으로 로그인.
